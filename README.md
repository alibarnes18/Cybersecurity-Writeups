# Cybersecurity Writeups

This repository contains my hands-on web security writeups based on PortSwigger Web Security Academy labs.

The goal of this repo is to understand how real-world web vulnerabilities work by practicing exploitation techniques and documenting each step clearly.

---

##  What You Will Find Here

Each folder represents a completed lab and includes:

- Vulnerability type (SQL Injection, XSS, CSRF, Access Control, etc.)
- Step-by-step exploitation process
- Payloads used during the attack
- Explanation of how the vulnerability works
- Suggested mitigation techniques

---

##  Topics Covered

- SQL Injection
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Authentication vulnerabilities
- Access control issues

---

##  Purpose

This repository is part of my learning path in web security and ethical hacking.  
It focuses on understanding vulnerabilities from an attacker’s perspective to build stronger defensive thinking.

---

##  Disclaimer

All testing is performed on legal lab environments provided by PortSwigger Web Security Academy.

No real-world systems are targeted.
